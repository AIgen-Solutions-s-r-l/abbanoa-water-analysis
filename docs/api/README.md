
# Roccavina Water Infrastructure API

Welcome to the Roccavina Water Infrastructure API documentation. This API provides a set of endpoints for monitoring and managing a water infrastructure system.

## Authentication

The API uses a mock authentication system for development and testing purposes. See the [Authentication](./authentication.md) section for more details.

## Endpoints

The API is organized into the following endpoint groups:

*   [Anomalies](./anomalies.md)
*   [Authentication](./authentication.md)
*   [Consumption](./consumption.md)
*   [Dashboard](./dashboard.md)
*   [Efficiency](./efficiency.md)
*   [Energy](./energy.md)
*   [Machine Learning](./ml.md)
*   [Nodes](./nodes.md)
*   [Pressure](./pressure.md)
*   [Readings](./readings.md)
*   [Weather](./weather.md)
