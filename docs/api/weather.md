
# Weather

The weather endpoints provide access to the weather data for the water infrastructure system.

*   `GET /api/v1/weather/current`: Get current weather data.
*   `GET /api/v1/weather/historical`: Get historical weather data.
*   `GET /api/v1/weather/statistics`: Get weather statistics.
*   `GET /api/v1/weather/locations`: Get all available weather station locations.
*   `GET /api/v1/weather/impact-analysis`: Analyze weather impact on water consumption and system performance.
