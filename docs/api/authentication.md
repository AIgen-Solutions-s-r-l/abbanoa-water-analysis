
# Authentication

The API uses a mock authentication system for development and testing purposes. The following endpoints are available:

*   `GET /api/v1/auth/me`: Get the current user.
*   `GET /api/v1/tenants/current`: Get the current tenant.
*   `POST /api/v1/auth/login`: Mock login endpoint.
*   `GET /api/v1/auth/tenants`: Get user tenants.
