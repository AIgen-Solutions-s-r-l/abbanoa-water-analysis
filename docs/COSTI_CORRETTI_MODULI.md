## PRINCIPALI CORREZIONI APPLICATE

### ❌ Errori Originali → ✅ Correzioni

**1. Costi Personale Irrealistici**
- ❌ Originale: €500-2,000/mese per "Persone"
- ✅ Corretto: €3,000-5,000/mese (0.5-0.7 FTE caricato)
- **Motivo**: 1 FTE costa €7,000-10,000/mese con tutti i carichi

**2. Costi Base Azzerati in Esercizio**
- ❌ Originale: €0/mese da M3 in poi
- ✅ Corretto: €7,000/mese ricorrenti
- **Motivo**: Infrastruttura, personale, sistemistica sono costi fissi continuativi

**3. Sviluppo Troppo Concentrato**
- ❌ Originale: Setup 2 mesi, poi quasi zero
- ✅ Corretto: Setup 2 mesi + manutenzione continuativa
- **Motivo**: Software richiede bug fixing, updates, features minori continui

**4. Infrastruttura Sottostimata**
- ❌ Originale: €500-800/mese fissi
- ✅ Corretto: €500 → €1,200/mese crescenti
- **Motivo**: Più clienti = più storage, compute, bandwidth

**5. Mancanza API Esterne**
- ❌ Originale: Non previste
- ✅ Corretto: €300-600/mese per PREMIUM
- **Motivo**: Meteo, dati agricoltura, socio-demo hanno costi API

### Opzione A: Sviluppo Parallelo (Aggressive)

**Costo**: €569k

- Diversificazione offerta immediata

**Contro**:
